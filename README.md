# 离职清理 Skill · Offboarding Cleanup

离职、归还电脑或设备交接前，**只检查这台电脑实际存在的软件**，按授权清理浏览器数据和本机登录凭据，让目标账号下次必须重新扫码或认证。

QQ、微信、飞书只是示例。先发现本机应用，再逐项处理：聊天、办公、会议、网盘、远控、音乐视频、游戏启动器、浏览器、输入法、开发工具、AI 客户端，以及没有预先列出名字的软件。

这是给支持 Agent Skills 的 AI 助手使用的工作流，不是双击即执行的清理程序。安装或阅读本 Skill 不会自动清理设备。

## 核心行为

- **本地发现优先**：从安装记录、当前用户应用、快捷方式和其他有界本地证据建立清单。未安装且无本机使用证据的软件不检查，不到云端遍历用户注册过的账号。
- **要求重新认证**：检查会话、Access Token、Refresh Token、设备票据、Cookie、站点存储、系统凭据库与免密恢复入口。关闭程序、取消自动登录或出现登录页都不自动算成功。
- **逐项核验**：目标账号正常重开后需要新扫码或交互认证才通过；仍能一键进入或被 SSO 自动恢复就记未完成。验证到认证挑战出现为止，不重新登录。
- **浏览器单独分项**：书签、全部时间历史、Cookie/站点数据、密码、通行密钥和同步状态分别处理，避免删除传播到云端或其他设备。
- **开发凭据与资料交接**：覆盖 SSH/agent、Git/CLI、云凭据和敏感文件盘点，区分本机移除与远端撤销。
- **保留明确范围**：聊天记录、下载文件、工作资料、其他设备和未选中账号按约定保留。认证存储混有业务数据时，不用整目录删除代替定位。

## 覆盖方式

| 本机发现类别 | 识别提示（示例，不是适配承诺） |
|---|---|
| 聊天与协作 | QQ、微信、企业微信、飞书、钉钉、TIM |
| 办公、会议、邮箱 | WPS、腾讯会议、网易邮箱大师、Foxmail，以及本机其他客户端 |
| 网盘与同步 | 百度网盘、阿里云盘、夸克网盘、天翼云盘、坚果云、OneDrive |
| 远程控制 | 向日葵、ToDesk、RustDesk，以及其他本机远控工具 |
| 音乐、视频、游戏 | QQ音乐、网易云音乐、爱奇艺、腾讯视频、WeGame、游戏启动器等 |
| 浏览器与网页应用 | 主流/国产浏览器的实际配置文件、PWA、登录扩展 |
| 开发、AI、系统工具 | IDE/插件、CLI、云工具、输入法同步账号等 |
| 未知或便携软件 | 仍列入本机清单，按实际版本和认证存储走通用流程 |

不维护“只支持这几个软件”的白名单，也不承诺任何版本都能自动删除登录凭据。**每个发现项都要有结果**：已验证、待用户/管理员、失败、未验证、无登录功能或其他明确状态。未知应用不会被悄悄算作完成。

Windows 有较详细的本机发现流程；macOS/Linux 使用各自系统的本地应用与凭据入口。实际可执行程度取决于宿主助手的终端、桌面控制与账号权限。

## 安装

通过 Skills CLI：

```bash
npx skills add mvlberry/offboarding-cleanup --skill offboarding-cleanup
```

或者下载本仓库，把整个目录放入目标助手的技能目录，保留 `SKILL.md`、`agents/` 和 `references/`。不要只复制一个 Markdown 文件。

安装本身不授权删除、退出任何账号或扫描个人数据。

## 使用

先只读盘点：

```text
使用 $offboarding-cleanup，检查这台电脑本机实际存在的软件，
列出需要清除的登录凭据和浏览器资料，不输出 Token/密码，先不删除。
```

完整离职清理需求：

```text
我要归还这台电脑。先发现全部本机软件并展示具体清单，
随后按我确认的范围清除本地 Token、会话和免密授权，
使目标账号下次必须重新扫码或认证。
包含浏览器书签和所有时间历史、SSH 与开发凭据；
保留工作交接资料、聊天记录、手机和云端数据。
```

只清理某些应用：

```text
只处理本机 WPS、百度网盘和腾讯会议的登录凭据，
让下次使用需要重新认证，保留本地文档和下载文件。
```

已有具体清单并已授权时会继续执行，不逐个文件重复询问。遇到新范围、混合数据存储或共享 SSO，才单独处理范围冲突。

## 如何判断完成

1. 每个发现的软件实例、账号和浏览器配置文件都有记录。
2. 本机认证存储的清除/失效化结果与应用重开后的认证行为分别有证据。
3. 普通退出后仍能复用旧会话，结果为未完成；无法观察行为则为待验证。
4. 本地删除不会被描述成 Token 在服务端全局失效。
5. 最终汇总覆盖数与未完成项，不用“已清三个常用软件”代表全机完成。

没有桌面控制时，可以精确处理已可靠定位且可分离的本机认证存储；没有可信定位证据则交给用户操作。不会按一个跨版本的猜测路径递归删除整个 AppData、聊天目录或系统凭据库。

## 验证与贡献

用 Python 3.10+ 运行：

```bash
python scripts/validate_skill.py
```

验证器只读取本仓库中明确列出的源码文件，检查元数据、引用完整性及常见误提交内容，不读取安装软件、浏览器或凭据数据。这不能代替真实产品版本的行为验证。

新增产品说明时请提供官方来源、适用版本、认证与业务数据的边界、仅本机的处理范围和验证方式。不要提交真实盘点报告、账号、Token、Cookie、私钥或聊天/浏览记录；示例使用虚构数据。
