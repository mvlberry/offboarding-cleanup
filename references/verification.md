# 操作清单与验收

## 计划与授权记录

在对话或用户批准的本地报告中维护下面的字段。无需固定新建文件；若写报告，避免默认放入同步盘或待删除目录。不记录秘密值、完整账号、内部主机或浏览/聊天内容。

| 字段 | 内容 |
|---|---|
| 对象 | 设备/目标用户别名、应用、浏览器配置文件、凭据类别 |
| 定位 | 执行时核对的精确本机位置；报告可脱敏 |
| 动作 | 删除书签/所有时间历史/站点数据/保存密码、清除指定应用本机 Token/会话/免密授权以要求新认证、移除指定凭据等 |
| 范围 | 仅本机、指定设备会话、云端、其他设备；不得合并成一个“清理”状态 |
| 保留 | 云端资料、其他设备、工作交接目录、聊天记录等 |
| 授权 | 已有用户指令或清单确认；尚未授权的单列 |
| 影响/恢复 | 会退出哪些账号；是否永久删除；已选择保留的位置或明确不备份 |
| 验收 | 用什么观察证明目标达成，不能以命令退出码代替应用状态 |
| 结果 | 已验证 / 用户反馈完成 / 已执行未验证 / 待用户 / 待管理员 / 失败 / 跳过 / 不适用 |

执行遇到锁定、权限不足、SSO 自动登录或 UI 与说明不一致，不盲目重试删除或提升权限。记录错误类别，定位原因，更新计划；不把工具错误中可能携带的路径/密钥原样输出。

## 按目标验收

全机任务先按[本机软件发现](installed-app-discovery.md)对账：每个应用实例都必须对应一个结果，未识别或无法核验的保留在清单中。只有本机发现的软件/认证宿主进入范围，不将云端账号列表、手机应用或未安装品牌作为补扫目标。

| 目标 | 足够的观察 | 不能据此判定成功 |
|---|---|---|
| 书签 | 指定配置文件的用户书签文件夹和管理页已空；托管项明确例外 | 清历史、隐藏书签栏、删除一个 Bookmarks 文件 |
| 历史 | 清理范围为“所有时间”，历史页不再显示旧记录 | 只选最近一小时、清缓存；验证操作自己产生的新记录也需说明 |
| 浏览器登录态 | Cookie/Token 等站点数据已按范围处理；目标站点无法复用原会话并要求新认证，SSO/扩展/同步入口另核对 | 只清缓存或历史、只删密码、只关标签、只注销浏览器同步 |
| 保存密码/通行密钥 | 当前版本的密码管理器中，目标本机条目已按范围移除；同步/系统/硬件存储各有状态 | 清 Cookies、密码库文件大小为零、宣称清网页缓存等于删通行密钥 |
| 本机应用（包括 QQ/微信/飞书及其他发现项） | 目标账号在正常重开后必须新扫码/交互认证，旧会话不能恢复；全部账号都清理才需停在登录页，保留 B 时可显示 B 且不应影响 B | 退出进程、仅按退出按钮、卸载应用；看到登录页但仍可复用旧票据；以未授权账号仍登录判断失败 |
| 本地 Token/刷新凭据 | 产品清除/失效化结果或精确存储移除结果与新认证行为分别有记录；缺一项时说明可见证据范围 | 仅删除 access token 留着 refresh token、只移到备份/回收站、宣称删除等于服务端全局失效 |
| 自动登录 | 所选账号不能通过记住密码、设备票据或 SSO 恢复原登录；共享恢复入口未解决就记“未达到重新认证要求” | 只关闭自动登录开关、有登录按钮就认为必须新认证 |
| SSH | 指定私钥文件/获准副本不存在，相关 agent 身份移除；远端授权另有结果 | 只删 `.pub` 或 `known_hosts`；磁盘删除但 agent 仍缓存 |
| 系统/CLI 凭据 | 对应受支持界面/命令显示本机条目或会话已移除 | 删配置文件但未检查系统凭据库；本地注销等同远程 Token 失效 |
| 本地资料 | 清单中的对象已处理，已保留资料可访问，云端状态未被误改变 | 文件夹大小减少、清空缓存或回收站等同所有副本消失 |

验证过程中不要重新登录来“试试看”，避免生成新 Token/会话。应用可以有匿名或已有安全脱敏数据的验证；真实网络访问仅在任务授权内。浏览器自动跳转主页可能创建新历史，这不代表原始清理失败。

## 结果报告

用简短表格汇报选中对象的本机状态、外部状态、验证依据及剩余动作。缺少桌面/账号权限时如实区分用户确认与工具观察。全机任务汇总本机发现数、已评估数、需要认证处理数、已验证数、待办数及无登录功能项；不能用前三个常见软件的结果代表全部，也不能把未知项计作已通过。

包括本次未覆盖的其他系统用户、便携目录、WSL/虚拟机、历史备份、服务端记录或企业管理项，但只提与本机发现有关的限制，不列无关风险清单。报告保留项及已批准导出的敏感副本去向（脱敏）。

最后退出本次工作依赖的 AI/账号之前，先给出简洁接续步骤；否则 agent 失去会话后不能再声称验证成功。此类动作可以标记“待用户完成最后一步”。
