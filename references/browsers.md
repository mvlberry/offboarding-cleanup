# 浏览器清理

目标逐项分开：书签/收藏夹、浏览与下载历史、Cookie/站点数据（登录态）、保存密码、通行密钥、同步/浏览器账号、缓存/自动填充。用户没有要求的类别不要自动增加为删除项。

登录清理遵循[本机重新认证](local-reauth.md)：目标网站下次访问需要新认证，不能复用旧 Cookie、localStorage/IndexedDB 中的 Token 或其他站点存储恢复登录。通过浏览器支持的站点数据清理处理这些类别，不用仅清图片缓存代替。浏览器/系统 SSO 或扩展仍能重新签发会话时如实标记限制。

## 定位全部目标配置文件

优先在浏览器配置文件界面和版本/配置页面确认当前实际路径，记录配置文件别名和同步状态。Default、Profile 1 等只是常见命名；每个选中配置文件分别验收，便携版和自定义 `user-data-dir` 另核对。

以下是 Windows 候选位置，不是删除命令：

| 浏览器 | 常见用户数据入口 |
|---|---|
| Chrome | `%LOCALAPPDATA%\Google\Chrome\User Data` |
| Edge | `%LOCALAPPDATA%\Microsoft\Edge\User Data` |
| Brave | `%LOCALAPPDATA%\BraveSoftware\Brave-Browser\User Data` |
| Firefox | `%APPDATA%\Mozilla\Firefox`；通过 `about:profiles` 核实根目录和本地目录 |

Safari、其他 Chromium 浏览器、macOS/Linux 和商店/沙箱版本按当前设置或官方帮助发现真实位置，不套用 Windows 路径。无权限/目录不存在只说明该入口不可见，不能推出整台机器没有数据。

不要为了盘点而打开整个 History、Cookies、Login Data、logins.json 或密码库，将内容传入模型。界面只记录计数/空状态；获准的程序化计数应在本机只读处理并仅输出汇总，禁止拷贝数据库到临时目录或导出密码。

## 首先处理同步范围

仅清本机时，先核实用户保留云端和其他设备资料的意愿，再通过浏览器的受支持流程退出同步/浏览器账号。Chrome 的账号存储、Google Password Manager 与传统 Sync 开关并非可简单视作同一层；必须确认后续删除作用于本机。

关闭同步或退出账号也可能出现“同时清除本机资料”的选项：核对其具体类别是否均在授权范围内。不要为了便利选择“删除所有账号数据”、删除 Microsoft/Google 云端活动或整条 Brave Sync 链。

若当前 UI 无法区分本机与云端密码，暂停这一个存储的删除，继续独立清理。不要借助退出后重新登录来确认同步，因为会重新下载数据。

## 各浏览器操作

### Chrome

1. 用当前版本账号界面退出 Chrome/解除该 Profile 的账号关联，核对本机保留/删除选项和云端影响。
2. 在“删除浏览数据”设置中选“所有时间”，仅选择已批准的历史、Cookie/站点数据、下载历史、缓存、自动填充等类别。
3. 单独进入书签管理器（通常可用 `chrome://bookmarks`），删除获准的用户书签。检查书签栏、其他书签、移动书签等实际存在的根文件夹及嵌套内容；全选可能只针对当前文件夹。企业托管书签交给管理员。
4. 单独查看当前版本的 Google Password Manager。官方文档指出普通清除浏览数据不删除其中的密码和通行密钥；不能假定“高级”里一定有密码选项，也不能清 Cookies 后报告密码已删。仅处理范围明确的本机凭据，云端库另授权。
5. 如果用户明确批准删除整个 Profile，可使用 Chrome 自带的配置文件移除功能；先确认所有该 Profile 的书签、历史、密码、设置等都在删除范围内，且不影响其他 Profile。不要强删整个 `User Data` 目录。

### Edge

1. 设置 → 个人资料 → 同步，按仅本机目标关闭同步，并按范围退出浏览器账号；核对企业 SSO 是否会恢复登录。
2. 设置 → 隐私、搜索和服务 → 清除浏览数据，选择全部时间和批准类别。名称以现场版本为准。
3. 单独通过收藏夹管理器删除选中的用户收藏夹，核对各文件夹；密码管理器中的保存密码/通行密钥单独处理。
4. 同步打开时删除历史、密码等同步项目可能传播到其他设备；不要在无法确定范围时继续。

### Firefox

1. 退出 Mozilla 账号时，“删除此设备上的数据”可作为本机清理路径，但只有其列出的全部类别都已获准才勾选；它不会删除其他同步设备的数据。
2. 否则退出同步后，用历史清理界面选择“全部/Everything”，覆盖批准的历史与 Cookie/站点数据。
3. “管理书签”中逐个选定书签根文件夹删除；在密码管理器中单独删除批准的保存密码。
4. `Active Logins` 只涉及 HTTP Basic 身份验证，不能代替 Cookie 登录态清理。账号网页远程移除同步设备不会删除它的本机数据。

### Brave

1. 在当前设置中核实离开/移除此设备的 Sync 选项，只处理当前设备。
2. 在清除浏览数据中选全部时间和批准类别；书签在 `brave://bookmarks` 单独处理，密码和自动填充分别验收。
3. 不用 `Delete Sync Account` 代替本机退出：它删除整个服务端同步链，却不会删除各设备已有本地数据。
4. 不删除整个用户目录作为快捷方式，其中可能有 Brave Wallet/Rewards 数据；钱包密钥不在一般浏览器清理授权内。

### 其他浏览器

Safari 必须将书签、历史、网站数据、Passwords/iCloud Keychain 分别核对，并先明确 iCloud 同步边界。其他浏览器按同样目标分类，依据当前官方帮助和实际 UI 执行；无法验证的类别记录为待处理，不臆造路径或套用 Chromium 数据库删除。

## 登录态与密码的补充

- 删除保存密码不会自动退出已登录网站；清 Cookie 不会撤销所有服务端 Token；退出浏览器同步也不等于退出全部网页账号。
- 通行密钥可能在 Google/Microsoft 密码管理器、Windows Hello、手机、硬件安全钥匙或第三方管理器中。Windows 11 可从设置 → 账号 → 通行密钥检查本机条目；仅移除获准的指定条目，不重置整个 Windows Hello/TPM。
- 企业 SSO、系统账号、扩展里的密码管理器可能让登录恢复；记录这些来源，按授权退出对应应用。不要通过移除企业管理来解决。
- 下载历史不是下载文件；网页自动填充、支付信息、扩展存储和密码管理器扩展里的数据分别列项，不宣称浏览器一次清理覆盖它们。

## 没有浏览器/桌面操作工具时

给出具体到应用和目标类别的简短操作步骤，先解释同步边界，让用户在本机操作并确认观察到的空状态/登录状态。工具只能读文件时，不能直接删除书签文件、SQLite/WAL/SHM 或整个 Profile 来模拟 UI 清理。

用户另行指定离线文件清理时，先形成该版本的专门计划：关闭应用、确认占用/重建行为、精确的 Profile 与文件集合、同步已脱离、恢复选择、重新打开验证。没有这些证据就保留为人工步骤，不能为了完成率扩大删除范围。
