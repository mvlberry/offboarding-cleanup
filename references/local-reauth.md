# 本机登录凭据清理：下次必须重新认证

## 达成的效果

这台电脑无法继续复用目标账号的旧登录状态。应用重开后应要求新扫码、密码输入及产品要求的验证码/手机确认等交互认证，具体方式由产品支持决定。不能保证所有产品只允许二维码，但必须排除旧凭据直接进入或后台恢复账号。

仍显示账号昵称/头像不必然失败：它可能只是非认证的账号选择记录。关键在于该账号是否还具有活动会话、能否无新认证恢复。相反，出现登录页或取消“自动登录”也不证明 Token 已清除。

## 识别本地的恢复链

先由[本机软件发现](installed-app-discovery.md)确定实际应用实例；再逐项盘点认证来源，避免读取秘密值。品牌名单仅帮助识别，不限制流程适用范围，也不构成跨版本适配保证：

1. 运行进程中的活动会话和后台/托盘进程。
2. 应用专用的 Token/刷新 Token、设备票据、WebView 登录存储、记住密码或免密授权。
3. 浏览器 Cookie、localStorage、IndexedDB、站点数据和相关扩展中的登录状态；普通磁盘/图片缓存不是同一类别。
4. Windows 凭据管理器、macOS 钥匙串、Linux Secret Service 或应用自己的加密存储中的目标条目。
5. 系统 SSO、浏览器账号、同步、手机授权或其他账户代理是否能重新签发会话。

文件名包含 `token` 不是删除证据。结合当前应用版本、官方支持操作、实际用户数据位置和账号映射确定存储，报告仅给类别、位置别名和状态，不输出 Token、密钥、Cookie 或存储正文。

## 执行顺序

1. **正常注销当前会话。** 使用应用提供的退出登录/移除本机账号功能。正常注销可让应用做自身的会话清理；在可用时先做它，再清磁盘残留。不要先断网、直接强杀程序，导致本可完成的注销遗漏。
2. **关闭可复用的免密入口。** 对目标账号处理自动登录、记住密码、信任此电脑、设备免密授权。只关自动登录可能仍保留凭据，继续核对后一项。
3. **精确清理仍存留的认证状态。** 优先用官方“清除登录信息/移除账号/重置登录凭据”等功能或受支持的 CLI。若需要本地文件/系统库处理，按下文条件精确移除目标认证记录，包括实际可确认的刷新凭据；不要仅删短期 access token 留下能重新签发的 refresh token。
4. **防止写回。** 应用内注销完成后，对离线清理涉及的客户端和后台进程正常退出，核对释放占用，再操作。记录其他同步/账号代理是否会重建凭据。不为清理而停用企业 SSO/管理，不删除整个系统账号库。
5. **重开验证。** 用当前环境原有网络状态正常启动应用，观察旧账号会否自动恢复；不得通过断网或屏蔽服务器制造“登录失败”来当作成功。只观察/检查认证要求，不提交可复用旧凭据进行真实登录，也不完成新扫码。

标准应用注销附带的当前会话失效无需额外扩大为全账号吊销；独立撤销其他设备、云端账号或服务端长期密钥不在本机目标内。若只有手机或管理员才能关闭此电脑免密授权，列为该项的待办，不笼统报告完成。

## 允许精确删除本地认证存储的条件

- 已确定目标设备、操作系统用户、应用版本和账号；授权已覆盖这个账号的本机登录凭据。
- 实际存储已核实，能说明它保存认证状态，不能仅凭网文旧路径、文件名或整个 `AppData` 目录猜测。
- 目标是可分离的认证专用文件/目录、系统库条目或应用支持移除的账号记录。确认不会连带删除聊天记录、下载附件、用户文档、其他账号或其他应用的凭据。
- 若存储混有聊天/配置/多个账号，优先产品支持的选择性注销/重置；只有验证了当前版本的选择性移除方法才执行。不能直接删混合数据库或凭猜测写 SQL。无法分离时列明范围冲突，再提供可审查的替代方案。
- 解析绝对路径、核对路径边界和链接，不跟随未核实的 Junction/symlink 清到其他位置；正常退出相关进程后，使用原生安全文件 API 或 PowerShell `-LiteralPath` 处理明确目标。
- 不自动导出或复制凭据作为回滚。不把仍可复用的 Token 丢进一个普通备份目录，或只移到回收站后就宣称本机没有凭据副本。采用用户已批准的精确移除方式；若工具只能移到回收站，报告该残留而不是清空整台电脑回收站。

没有桌面工具不代表一律无法清理：有已核实的独立认证存储且上述条件成立，可以通过终端清理本机 Token。没有可信定位证据时，不写跨版本“万能路径删除脚本”。完成文件移除但不能观察应用重开结果，只记“认证存储已移除，重新认证待验证”。

## 验收与报告

对每个目标账号分别记录：

| 项目 | 可接受的状态 |
|---|---|
| 本地认证存储 | 已通过产品功能清除/失效化，或指定独立认证存储已移除；未观察内部状态时如实说明 |
| 免密恢复入口 | 自动登录、记住密码及实际存在的设备票据等已处理；共享 SSO 限制独立列出 |
| 应用行为 | 正常重开后目标账号没有活动会话，使用该账号要求新扫码/交互认证；不通过真实登录验证 |
| 保留范围 | 手机/其他设备会话、云端资料、未选中账号和聊天档案按约定保留 |
| 服务端有效性 | 仅按官方注销/设备管理的返回结果陈述；本地删除不证明复制出去的 Token 已全局失效 |

如果仍可一键进入或后台刷新会话，结果必须是“未达到目标”，继续定位授权范围内的恢复来源；不能因已按过退出按钮而改写为完成。如果只能看到登录页而无法排除旧凭据复用，报告“已退出，重新认证待验证”。

聊天记录与附件默认保留。本地会话失效不会消除这些资料的可读性；用户同时要求清理它们时，按单独的数据清理项处理。

“本机全部软件”任务需把每个发现项记为已评估：有登录则按上述状态验收；无登录能力、已经要求新认证、仅系统组件或未识别版本分别说明。不可检查/未知不是“无需清理”。不得为保证全集完成而擦除整个 AppData、系统账号库或用户目录。
