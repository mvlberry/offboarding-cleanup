# 本机各类应用：清登录凭据并要求重新认证

本 Skill 的离职登录清理以[本机重新认证](local-reauth.md)为核心：目标账号的旧会话/Token 和免密授权不能再用于这台电脑，下次需要新扫码或产品支持的交互认证。每个目标账号分别记录本机活动会话、可复用认证存储、自动/免密恢复入口、本地历史与附件。清本机 Token 不默认授权删除聊天或永久注销账号。

先读取[本机软件发现](installed-app-discovery.md)。以下 QQ、微信、飞书是较详细的操作示例，不是只处理这些软件的白名单；其余本机发现的应用全部进入下面的通用流程。只有发现存在的产品才核对当前官方帮助；不去云端批量找用户账号。

## 每个发现应用的通用流程

1. 确认产品、版本、发行渠道、当前用户实例与账号别名。没有登录功能或没有可复用凭据，记录原因而不是尝试清理不存在的 Token。
2. 定位实际可用的退出登录、移除本机账号、清登录信息、关闭免密/记住密码等功能；按核心流程确认系统库、WebView、刷新凭据和 SSO 是否会恢复登录。
3. 先用产品支持的方法处理；仍有独立认证存储时，满足精确定位条件才删除。不能因同为 Electron/Chromium 就递归删除所有 `Local Storage`、`IndexedDB` 或 `User Data`，其中也可能是文档、草稿或其他账号数据。
4. 正常重开并按目标账号验证；需新认证时停止，不实际扫码。保留其他账号时按账号验收；遇到系统共享登录无法分离就记未完成。
5. 对未知软件采用同样流程，可依据当前官方帮助和可见 UI 建立该版本的方法；没有可信方法不能假定已适配，也不能从覆盖表中删去。

## 按类别增加的检查

这些类别只对本机发现项生效；名字是识别提示，不证明固定版本已验证。

| 类别与示例 | 本机认证重点 | 应保留或另列的内容 |
|---|---|---|
| 聊天/协作：QQ、微信、企业微信、飞书、钉钉、TIM | 多账号、记住登录、设备免密、WebView 与系统账号库 | 聊天、附件、组织成员身份 |
| 办公/会议/邮箱：WPS、腾讯会议、网易邮箱大师、Foxmail、石墨/语雀客户端 | 文档云账号、会议单点登录、邮箱密码/OAuth 缓存 | 离线文档、邮件、草稿、正版授权 |
| 网盘/同步：百度网盘、阿里云盘、夸克网盘、天翼云盘、坚果云 | 先解除本机同步/账号关联，再处理 Token 和免密 | 云端文件、离线副本、未完成上传 |
| 远控/传输：向日葵、ToDesk、RustDesk 等本机发现项 | 账号会话、设备绑定、保存的远端凭据、本机无人值守访问授权分别列项 | 正在使用的远程连接；其他设备绑定。撤销本机无人值守访问是单独列明的本机授权项 |
| 音乐/视频/内容：QQ音乐、网易云音乐、酷狗、爱奇艺、腾讯视频、优酷、哔哩哔哩/抖音客户端 | 本地账号、会员登录票据、网页或客户端多个入口 | 下载媒体、收藏内容、云端订阅 |
| 游戏/启动器：WeGame、米哈游/网易等启动器及其他本机发现平台 | 启动器和游戏内账号可能各有票据；快速登录/设备信任 | 游戏存档、安装文件、购买许可 |
| 输入法/安全/驱动/硬件软件：搜狗/百度/QQ输入法及本机发现产品 | 同步词库或个人云账号等实际登录功能 | 本地词库、防护服务、驱动、企业管理与激活 |
| 开发/AI/云工具：IDE、AI客户端/CLI、Git、容器/镜像仓库、云控制台工具 | 插件、CLI、环境变量、API Key、系统库、网页登录分别核对 | 源码、项目 `.env` 中非认证配置、模型/数据库；当前执行者最后处理 |
| 网页应用/PWA/浏览器扩展 | 当前本机 Profile 中的站点会话、扩展自己的账号状态 | 云端资料、未安装服务。密码管理器扩展不因清浏览历史就视为退出 |

不因为例子未列出某品牌就跳过已发现应用，也不为凑全品牌清单而安装应用或打开其网站登录页。只核对本机证据指向的产品。

操作前确认没有未发送草稿、文件传输或未交接工作；发现问题时只暂停对应退出项。优先应用内账号功能；关闭窗口、托盘退出、结束任务和卸载均不足以证明认证会话已经失效。

## 飞书

官方入口为桌面头像 → 退出登录。多账号可退出当前账号或退出所有账号；“退出所有账号”指该客户端的账号，不要混同为退出所有设备。只选用户批准的账号集合。

在目标账号登录页核对“记住我的登录状态”及当前版本可见的自动登录选项，能在未登录状态关闭就关闭，不为修改它重新登录。若仍能恢复旧会话，使用当前版本支持的本机账号移除/登录信息清理，或按核心流程精确清理已核实的独立认证存储。重新打开后，目标账号必须要求新扫码或认证；若保留 B，可正常显示 B，只检查不能直接切回 A 沿用旧会话，不影响 B。

需要撤销此设备的远程会话时，在授权范围内从头像 → 设置 → 账号与安全 → 账号安全中心 → 登录设备，核对设备身份后退出；手机端入口从设置中的账号安全中心进入。界面/账号类型可能不同，豆包账号登录需按其账号管理入口处理。

“账号注销”是永久删除账号与数据，不能用作离职电脑退出。飞书中的组织成员移除或企业账号停用也属于管理员交接，不能由本机清理自动推定。

## QQ

依据当前客户端账号/设置菜单找到实际“退出登录/切换账号”的动作，检查自动登录、记住密码等当前存在的选项。旧版文档的左下角“退出”可能只是应用退出，不把它写成当前 NTQQ 的固定注销入口或成功依据。

退出后核对登录界面、账号选择列表和自动登录状态；登录页若仍可一键进入旧账号，说明重新认证目标尚未达到。继续使用支持的“删除本机登录信息/移除本机账号”等实际存在的功能，或精确清理经核实的独立认证存储。删除账号选择列表上的昵称记录不证明 Token 被清除，须重开复核。

腾讯官方资料明确退出后再次登录仍可能看到此前数据，因此 QQ 本地消息、附件、图片和备份必须单独列为保留/清理项。不要整目录删除 Tencent、QQ 或聊天数据来代替注销。

## 微信

使用当前电脑客户端可见的账号“退出登录”功能，检查该电脑自动登录授权。随后验证是否要求新的扫码/手机认证；若仍可直接点登录恢复账号，继续处理本机登录票据和免密授权。仅关闭自动登录或“退出微信/关闭程序”都不足以完成目标。

用户手机如显示此电脑的活动登录，可由用户选择“退出该设备/关闭自动登录”等实际提供的动作。设备管理中的“删除曾登录/信任设备”不一定会终止当前活动会话；页面只说明“下次需要验证”时，只报告这一效果。

本 Skill 创建时未核实最新版微信官方精确菜单路径；现场以应用内帮助或可访问的腾讯官方资料为准，不编造固定路径。扫码、验证码和生物识别由用户本人完成，不让用户把验证码或授权二维码发到聊天里。

微信本地聊天数据库、图片、附件和手机备份在退出后可能保留；仅当用户明确要求清理这些数据时，确认当前客户端显示的实际存储路径、备份选择和删除影响后另行处理。不要猜测 `WeChat Files` 或新版目录名并整棵删除。

## 其他应用（发现且在范围内时）

| 应用 | 处理重点 |
|---|---|
| Teams | 用头像中的 Sign out；多账号分别处理。退出 Teams 不会移除 Windows 共享账号或其他设备会话，不用自制清目录脚本模拟注销 |
| Slack | 按目标工作区退出，浏览器会话另核对；“退出所有其他会话”影响其他设备，必须有相应授权。退出登录不等于退出工作区成员身份 |
| 钉钉/邮箱/VPN/远程桌面 | 使用当前版本明确的退出登录和账号移除入口，自动登录、保存密码、缓存分别核对；未核实的路径使用官方帮助 |
| OneDrive/其他云盘 | “取消链接此电脑”与清本地文件分别进行；先解除同步，核实后再处理获准的本地副本，避免删除传播到云端 |
| AI/IDE/密码管理器 | 确认其登录与扩展、CLI 凭据是否分离；执行本次任务依赖的账号最后退出，先留下接续清单 |

## 工具边界与验收

先发现当前环境是否有合法可用的桌面/应用控制工具；有则查看当前 UI 再操作，不靠固定坐标猜点。不安装未知自动化程序来接管账号。

没有桌面控制时，可按核心流程处理已有可信定位证据的独立认证存储；没有这种证据或需要手机确认时，提供短步骤并标记“待用户操作”。用户说已完成则记“用户反馈完成”；工具需观察到目标账号要求新认证才记行为验证通过。多账号场景不得为获得整个客户端的登录页而退出未授权账号。不要以指导已经发出作为完成。

正常重新打开应用验证，到新扫码/认证要求出现就停止，不完成登录。仍能复用旧凭据或被企业 SSO 自动恢复的账号标记未达目标；只有昵称仍在但必须重新认证，可以标记登录凭据清理达标，昵称隐私另按范围处理。远程退出仅针对已批准设备；用户的手机、家用电脑或其他工作设备不默认下线。要清聊天和附件时回到[凭据与资料流程](credentials-and-data.md)做单独计划。
